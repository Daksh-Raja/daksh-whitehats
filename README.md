## A recent cybersecurity incident

In October 2026, ConnectWise shut down customer access to its Cloud Backup service (formerly SkyKick Cloud Backup) after attackers accessed application identities and used them to breach Microsoft 365 tenants. Huntress reported at least 162 compromised tenants in its environment, and Microsoft later confirmed unauthorized authentication attempts tied to that service.

This is a supply-chain style incident: a trusted backup integration became a path into customer Microsoft 365 environments. It is a reminder that third-party apps with tenant-wide permissions need tight identity controls, monitoring, and a plan for when a vendor is compromised.

Source: [BleepingComputer — Hackers breach Microsoft 365 tenants via ConnectWise supply-chain attack](https://www.bleepingcomputer.com/news/security/hackers-breach-microsoft-365-tenants-via-connectwise-supply-chain-attack/)
